\# AutoKorea



A desktop app for filtering and scraping used-car listings from Encar. Configure vehicle filters, scrape a limited number of pages, review results, and save listings to a local SQLite database and timestamped Excel files.



\## Requirements



\- Python 3.9 or later

\- Internet connection

\- Dependencies listed in `requirements.txt`



\## Run



From the project folder:



```powershell

python -m pip install -r requirements.txt

python main.py
